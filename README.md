## This has all my config dotfiles, primarily for i3 window manager (DE)
### Also has for hyprland, all other application config will work in mostly any DE on Arch.
Happy Ricing!!

> Use `stow` to create symlinks (recommended)
#### Just type:
```bash
# stow 'folder-name'
# example:
stow nvim
stow alacritty
stow tmux

# This will create a symlink to the folder into ~/.config
```
